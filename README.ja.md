# y8960-tech-demo

![Y8960 TECH DEMO](demo/preview.gif)

openMSXで一曲を通して再生した映像です（約33秒・GIFは無音）。

**SILICON SYMPHONY** は、Y8960対応openMSXで演奏する約32秒のオリジナル音源デモです。一つの旋律に、SSGの左右の掛け合い、2系統のOPLL、OPL2の低音、ADPCMの打楽器が加わります。4つのセクションを自動で繰り返します。

独立したデモであり、openMSX・Y8960の公式プロジェクトではありません。バージョン **0.5.0** です。

## 起動

Windows 10/11 x64向けです。ZIP全体を、クラウド同期対象外の書き込み可能なローカルフォルダへ展開してください。

1. **setup-y8960.bat** をダブルクリックし、ハッシュ検査と起動確認の完了を待ちます。
2. **launch-y8960-tech-demo.bat** をダブルクリックします。

C-BIOSと通常のV9958画面を使います。実機BIOS・V9968・z88dk・Pythonは演奏に不要です。設定はこのプロジェクトのruntimeフォルダ内に保存します。

配布パッケージは [GitHub Releases](https://github.com/renatus-xxxx/y8960-tech-demo/releases) の `y8960-tech-demo-0.5.0.zip` を使用します。GitHubが自動生成する「Source code (zip)」ではなく、同名の配布アセットを選んでください。セットアップにはインターネット接続が必要です。

## setup BATが行うこと

`setup-y8960.bat` は同梱のPowerShellスクリプトを実行します。

1. Windowsが64bitか、配置先がリンク等を含まないローカルフォルダかを確認し、ログと二重実行防止のロックを用意します。
2. デモROMのSHA-256を確認します。未導入なら固定バージョンのエミュレーターZIPをcurl.exeで取得します。キャッシュがあれば再利用して検査します。
3. ZIPのSHA-256を検査し、一時フォルダへ展開してopenmsx.exeのハッシュも確認します。
4. C-BIOS、デモROM、Y8960拡張を画面・音声出力なしで起動し、デモの初期化と所定の音源デバイスを検査します。
5. 成功した環境をruntimeへ配置し、管理対象ファイルのハッシュを記録します。失敗時は作成した一時環境を片付け、logsに記録を残します。

再実行時は既存runtimeを検査し、再インストールやユーザー設定の初期化は行いません。ソースのビルドや音声の詳細測定は行いません。演奏にはlaunch BATを使います。PowerShellの実行ポリシー指定は起動するプロセスだけに適用し、Windows全体の設定は変更しません。

## 操作

| キー | 操作 |
|---|---|
| 1〜4 | セクションへ移動。その後も自動演奏を続けます |
| Space | 演奏の時間進行を一時停止／再開 |
| M | 時間進行を続けたまま消音／解除 |
| R | セクション1からやり直す |
| Esc | 使用中の音源を消音して停止。終了はウィンドウを閉じます |

1：SSGの旋律。2：もう一系統のSSGによるエコーと低音。3：2系統のOPLLと和音。4：OPL2低音と2つのADPCM打楽器です。

バーは**発音イベントの表示**であり、実際の音量測定やFFTではありません。LE=旋律、EC=エコー、BA=SSG低音、F0/F1=OPLL、OP=OPL2低音、KI=キック、SN=スネアです。曲と合成した打楽器はオリジナルです。Python/Cで音や旋律を編集でき、楽譜を読む必要はありません。

## 困ったとき

- runtimeがない：先にsetupを実行してください。
- ハッシュ不一致：検査を回避せず、対応するZIP・ファイルを戻してください。
- 音が出ない：Windowsのアプリ別音量とMキーを確認してください。フォークは本体音源ではなくY8960側の出力を使います。
- setupの再実行では管理対象ファイルを検査し、ユーザー設定を保持します。別バージョンは新しいフォルダに展開してください。
- 設定のリセットはopenMSXを閉じて `runtime/user` を削除します。アンインストールはopenMSXを閉じてこのプロジェクトのフォルダを削除します。グローバルなインストールは行いません。
- エラーは `logs` または `runtime/user/stderr.log` に記録します。
